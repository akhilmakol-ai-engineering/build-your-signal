# Week 3 - One project, five angles

## Outcome

Turn one genuine project into a week of useful content without repeating yourself.

## Do the work

1. Pick a project with a real decision, obstacle, or lesson.
2. Use the [content calendar](../templates/content-calendar.md) to create five angles.
3. Draft one post using: **hook -> specific moment -> lesson -> invitation**.
4. Publish one post or save a ready-to-publish draft.
5. Schedule the next post while the project is fresh.

## Definition of done

- [ ] Five angles from one project
- [ ] One complete post
- [ ] A simple calendar for the next week

## Quality check

Replace broad claims with proof. “I learned leadership” is vague; “I changed the project handoff after two teammates got blocked” shows the lesson.
