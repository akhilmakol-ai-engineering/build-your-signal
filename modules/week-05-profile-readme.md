# Week 5 - Build your profile README

## Outcome

Create the homepage GitHub gives you: a concise guide to your work, direction, and next conversation.

## Do the work

1. Create a public repository with the exact same name as your GitHub username.
2. Start from the [profile README template](../templates/profile-readme.md).
3. Lead with a truthful one-line statement, then show your strongest work.
4. Link to LinkedIn, a case study, and only the contact paths you are comfortable sharing.
5. Preview on mobile and remove anything that distracts from the story.

## Definition of done

- [ ] A clear opening statement
- [ ] Two or three project links with outcomes
- [ ] Current learning or building focus
- [ ] Working links and an appropriate contact path
