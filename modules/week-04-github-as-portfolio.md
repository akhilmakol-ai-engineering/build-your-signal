# Week 4 - GitHub as portfolio

## Outcome

Make three repositories easy for a recruiter, collaborator, or peer to understand.

## Do the work

1. Choose three repositories that best support your story. They do not need to be your biggest projects.
2. Archive, hide, or de-emphasise work that does not represent you well.
3. Rewrite each README with the [project README template](../templates/project-readme.md).
4. Add a visual, demo, or clear evidence link where it helps.
5. Pin the three repositories on your GitHub profile.

## Definition of done

- [ ] Three repos are pinned
- [ ] Each README opens with problem, outcome, and audience
- [ ] Each README explains an important choice or learning
- [ ] Links and setup instructions work

## Submit

Share the three links and ask: *Which repo gives the clearest proof of the direction I named in Week 1?*
