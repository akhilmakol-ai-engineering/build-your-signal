# Build Your Signal

> Your degree opens the door. Your signal shows what you can do.

This is a six-week, GitHub-native program for students who want to turn their work into a visible professional signal.

## Start here

1. **Fork this repository** to your GitHub account.
2. Open [the learner workspace](docs/START-HERE.md) and complete Week 1.
3. Work through one module per week. Save your drafts in your fork.
4. When a week is ready, [open a submission issue](../../issues/new?template=weekly-submission.md) in this repository for feedback.

## The journey

| Week | Focus | You will leave with |
| --- | --- | --- |
| 1 | [Find your story](modules/week-01-find-your-story.md) | A one-line positioning statement |
| 2 | [Rebuild LinkedIn](modules/week-02-rebuild-linkedin.md) | A clearer profile, section by section |
| 3 | [One project, five angles](modules/week-03-one-project-five-angles.md) | A week of content from one project |
| 4 | [GitHub as portfolio](modules/week-04-github-as-portfolio.md) | Three repos with strong README files |
| 5 | [Profile README](modules/week-05-profile-readme.md) | A GitHub portfolio homepage |
| 6 | [Ship the capstone](modules/week-06-ship-the-capstone.md) | A shareable case study and posting habit |

## By the end

- A LinkedIn profile built around a clear narrative
- Three GitHub repositories that show your thinking, not only your code
- A sustainable habit of sharing one useful post each week
- A GitHub Profile README that works as a homepage
- A 90-second introduction to who you are and what you build
- A capstone case study you can send to recruiters

## Repository map

- `modules/` - six guided weekly modules
- `templates/` - copy-and-adapt templates for every deliverable
- `docs/` - onboarding, feedback, and course guidance
- `.github/` - issue forms and submission workflow

## The three signals

| Signal | Purpose | Where it lives |
| --- | --- | --- |
| **Story** | Explain who you are becoming | LinkedIn |
| **Proof** | Show what you can do | GitHub |
| **Voice** | Share how you think | Posts and conversations |
