# Contributing

This course is built to help students make their work visible. Improvements are welcome.

## Before opening an issue or pull request

- Check that the suggestion supports Story, Proof, or Voice.
- Keep examples original, inclusive, and practical for students.
- Do not add personal data, client information, or copyrighted course material.
- Keep language direct and jargon-free.

## Changes we welcome

- Better explanations and clearer checklists
- Template improvements
- Accessibility fixes
- Additional examples that do not expose private information

For learner work, use a **Weekly submission** issue rather than a pull request.
